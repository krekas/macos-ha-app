# Glossary

One name per idea. Buttons, menus, tooltips, errors, and VoiceOver labels use these words only.

| Term | Means | Not |
| --- | --- | --- |
| Home Assistant | The user's HA server. Written out in full in UI text. | HA (except in code), hub, instance |
| Server URL | The address of Home Assistant, e.g. `http://homeassistant.local:8123` | host, endpoint, base URL |
| Access token | A long-lived access token created in the user's HA profile | API key, password, secret |
| Connect | Save the server URL and access token, then sign in | log in, link, pair |
| Connected / Not connected | Connection status, shown in Settings and by the menu bar icon | online/offline, linked |
| Entity | Anything in Home Assistant with a state: a light, switch, or sensor | device, thing, object |
| Menu | What opens when you click the HAApp icon in the menu bar | popover, panel, dashboard |
| Item | One entity added to the menu, with an optional custom name and symbol | row, tile, card, entry |
| Group | A titled section of items in the menu | folder, room, category |
| Add Entities… | Open the picker to add entities to the menu as items | import, select |
| Remove | Take an item out of the menu. The entity in Home Assistant is untouched. | delete (for items) |
| Turn On / Turn Off | Change a light or switch. The item itself acts as the toggle. | enable, activate, toggle (in UI text) |
| Not found | An item whose entity no longer exists in Home Assistant | missing, deleted, orphan |
| Unavailable | Home Assistant reports the entity's state as `unavailable` or `unknown`; shown as "—" | offline, error |
